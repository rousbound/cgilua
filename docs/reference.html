CGILua
Building Web Scripts with Lua

Headers

Headers functions are used to change the HTTP response headers:

cgilua.contentheader
cgilua.contentheader ( type string subtype string )
Sends a Content-type header with the given values of type and sub-type.
Returns nothing.
cgilua.header
cgilua.header ( header string value string )
Sends a generic header. This function should not be used to generate a Content-type nor a Location header because some launchers/web-servers use different functions for this purpose.
Returns nothing.
cgilua.htmlheader
cgilua.htmlheader ()
Sends the header of an HTML file (Content-type: text/html).
Returns nothing.
cgilua.redirect
cgilua.redirect ( url string args table nil )
Sends the header to force a redirection to the given URL adding the parameters in table args to the new URL. The args table can have pairs name = value that will be encoded (see cgilua.urlcode.encodetable).
Returns nothing.

Content Generation

Content generation functions are used to output text to the response and to generate URLs in the CGILua format:

cgilua.mkabsoluteurl
cgilua.mkabsoluteurl ( path string ) string
Creates an absolute URL containing the given URL path.
Returns the resulting absolute URL.
cgilua.mkurlpath
cgilua.mkurlpath ( script string args table nil ) string
Creates a URL path to be used as a link to a CGILua script using the optional table of arguments. The arguments are used in the URL as query string parameters.
Returns the resulting URL.
cgilua.print
cgilua.print ( ... any )
Sends the given arguments to the client. This function converts all its arguments to strings before sending them to the server thus it does not raise errors like cgilua.put.
Returns nothing.
cgilua.put
cgilua.put ( ... string number )
Sends the given arguments to the client. This function should always be used; do not use Lua's print or io.write for output otherwise your script may not work for every launching method.
Returns nothing.

CGILua Variables

CGILua Variables offers information about the script being processed and the CGI environment variables depending on the Web server and launcher used:

cgilua.script_file string
The file name of the running script. Obtained from cgilua.script_path.
cgilua.script_path string
The complete path of the running script. This variable is usually the same as the CGI environment variable PATH_TRANSLATED.
cgilua.script_pdir string
The directory of the running script. Obtained from cgilua.script_path.
cgilua.script_vdir string
The virtual directory of the running script. Obtained from cgilua.script_vpath.
cgilua.script_vpath string
The complete virtual path of the running script. Equivalent to the CGI environment variable PATH_INFO.
cgilua.servervariable
cgilua.servervariable ( varname string ) string nil
Returns a string with the value of the CGI environment variable corresponding to varname. For a list of CGI variables please refer to SAPI.Request.servervariable
cgilua.tmp_path string
The directory used by cgilua.tmpfile. Obtained by checking os.getenv("TEMP"), os.getenv("TMP") and "/tmp" in that order.
cgilua.urlpath string
The name of the script. Equivalent to the CGI environment variable SCRIPT_NAME.

Error Handling

CGILua error handling functions allow the redefinition of how errors are handled and presented to the user:

cgilua.errorlog
cgilua.errorlog ( message string )
Sends the given message to the error log file.
Returns nothing.
cgilua.seterrorhandler
cgilua.seterrorhandler ( func function )
Sets the error handler function. This function is called by Lua when an error occurs. It receives the error message generated by Lua and it is responsible for generating and returning the correct error message to be used by CGILua.
Returns nothing.
cgilua.seterroroutput
cgilua.seterroroutput ( func function )
Sets the error output function. This function is called by Lua to generate the error output itself.
Returns nothing.

CGILua Behavior

The behavior of CGILua can be configured using this set of functions:

cgilua.addscripthandler
cgilua.addscripthandler ( ext string func function )
Defines a function to pre-process files with a certain extension. The default configuration uses cgilua.doscript to process Lua Scripts (.lua files) and cgilua.handlelp to process Lua Pages (.lp files).
Returns nothing.
cgilua.addopenfunction
cgilua.addopenfunction ( func function )
Defines a function to be called before the execution of the script requested. If the function returns a value, it halts the execution and the value is assumed to be a URL for redirection.
Returns nothing.
cgilua.addclosefunction
cgilua.addclosefunction ( func function )
Defines a function to be called after the execution of the script requested.
Returns nothing.
cgilua.setmaxfilesize
cgilua.setmaxfilesize ( size number )
Sets the maximum size (in bytes) for each uploaded file. This value is bounded by the maximum total input size (see cgilua.setmaxinput). This function only takes effect if used before POST data is processed.
Returns nothing.
cgilua.setmaxinput
cgilua.setmaxinput ( size number )
Sets the maximum total input size allowed (in bytes). This function only takes effect if used before POST data is processed.
Returns nothing.

URL Encoding Functions

CGILua encoding functions allow the processing of URL strings:

cgilua.urlcode.encodetable
cgilua.urlcode.encodetable ( args table ) string
URL-encode the elements of a table creating a string to be used as a URL for passing data/parameters to another script.
Returns a string representing the encoded argument table.
cgilua.urlcode.escape
cgilua.urlcode.escape ( str string ) string
URL-encode a string.
Returns the encoded string.
cgilua.urlcode.insertfield
cgilua.urlcode.insertfield ( args table name string value string )
Adds the given value to the field indexed by name in the args table. If the field already has a value, it is transformed into a table with this value at index 1 and the new value at index 2.
Returns nothing.
cgilua.urlcode.parsequery
cgilua.urlcode.parsequery ( query string args table )
Parse URL-encoded request data. This could be the query part of the script URL or URL-encoded POST data. Each decoded name = value pair is inserted into the args table.
Returns nothing.
cgilua.urlcode.unescape
cgilua.urlcode.unescape ( str string ) string
URL-decodes a string.
Returns the decoded string.

Auxiliary Functions

cgilua.doif
cgilua.doif ( filepath string ) any nil
Executes a file if it exists. Returns the values returned by the execution, or nil followed by an error message if the file does not exist.
cgilua.doscript
cgilua.doscript ( filepath string ) any
Executes a file. Raises an error if it occurs. In case of success, returns the values returned by the execution.
cgilua.pack
cgilua.pack ( ... any ) table
Returns a new table with all the passed arguments stored in it.
cgilua.splitonfirst
cgilua.splitonfirst ( path string ) string, string
Returns two strings with the "first directory" and the "remaining path" of the given path string split on the first separator ("/" or "\").
cgilua.splitonlast
cgilua.splitonlast ( path string ) string, string
Returns two strings with the "directory path" and "file" parts of the given path string split on the last separator ("/" or "\"). This function used to be called cgilua.splitpath.
cgilua.tmpfile
cgilua.tmpfile ( dir string namefunction function nil ) string
Returns a temporary file in the cgilua.tmp_path directory using an optional name generator. If the name generator function is not passed, cgilua.tmpname is used. The file is removed by CGILua after the request has been processed.
cgilua.tmpname
cgilua.tmpname () string
Returns a temporary name using an adjusted version of os.tmpname.

Server API (SAPI)

The Server API (SAPI) allows the abstraction of a series of internal web server details and allows CGILua to be used over WSAPI. The reference implementation of WSAPI currently supports Apache, Microsoft IIS and Xavante as Web servers, and CGI, FastCGI as WSAPI connectors.

The SAPI API is separated into two packages: SAPI.Request and SAPI.Response.

SAPI.Request

SAPI.Request.getpostdata
SAPI.Request.getpostdata ( n number nil ) string
Gets a block of POST data. The optional parameter n is the number of bytes to read (a default block size is used if no parameter is passed).
Returns the block as a Lua string.
SAPI.Request.servervariable
SAPI.Request.servervariable ( varname string ) string
Gets the value of a server environment variable. The argument can be one of the defined CGI Variables:
  • AUTH_TYPE - Authentication method used
  • CONTENT_LENGTH - The length of the content
  • CONTENT_TYPE - The content type of the data
  • GATEWAY_INTERFACE - CGI specification revision
  • PATH_INFO - Extra path information
  • PATH_TRANSLATED - Physical path translation
  • QUERY_STRING - The query string data
  • REMOTE_ADDR - IP address of the client
  • REMOTE_HOST - Hostname of the client
  • REMOTE_IDENT - RFC 931 identification
  • REMOTE_USER - Authenticated username
  • REQUEST_METHOD - GET, HEAD, POST, etc.
  • SCRIPT_NAME - Virtual path to the script
  • SERVER_NAME - Server's hostname or IP
  • SERVER_PORT - Port number
  • SERVER_PROTOCOL - Protocol name/revision
  • SERVER_SOFTWARE - Server software name/version
Header lines are placed with the prefix HTTP_ followed by the header name (with - changed to _).
Returns a string.

SAPI.Response

SAPI.Response.contenttype
SAPI.Response.contenttype ( header string )
Sends the Content-type header to the client. The given header should be in the form "type/subtype". This function must be called before any output is sent.
Returns nothing.
SAPI.Response.errorlog
SAPI.Response.errorlog ( message string number )
Generates error output using the given string or number.
Returns nothing.
SAPI.Response.header
SAPI.Response.header ( header string value string )
Sends a generic header to the client. The first argument must be the header name, such as "Set-Cookie". The second argument should be its value.
Returns nothing.
SAPI.Response.redirect
SAPI.Response.redirect ( url string )
Sends the Location header to the client.
Returns nothing.
SAPI.Response.write
SAPI.Response.write ( ... string number )
Generates output using the given arguments. The arguments must be strings or numbers.
Returns nothing.
