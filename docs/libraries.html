CGILua
Building Web Scripts with Lua

Overview

CGILua includes a set of external libraries that allows the handling of cookies, serialized data and sessions. To use these libraries just require them in your CGILua config.lua or script file.

Cookies

cgilua.cookies.set
cgilua.cookies.set ( name string value string options table nil )
Sets the value of the cookie with a given name. The optional table options is used to give the values of the cookies attributes: expires, path, domain, secure. This function should be called before the HTTP headers are sent and before any output is generated, so it must not be used inside a Lua Page.
This function sends a cookie with the response. If you need to create a cookie inside the generated response or if the cookie needs to be set inside the client, use cgilua.cookies.sethtml instead.
Returns nothing.
cgilua.cookies.sethtml
cgilua.cookies.sethtml ( name string value string options table nil )
Sets the value of the cookie with a given name using an HTML meta tag. Use this when you need to set a cookie inside the generated HTML response body.
Returns nothing.
cgilua.cookies.get
cgilua.cookies.get ( name string ) string nil
Gets the value of the cookie with the given name.
Returns a string with the value of the cookie.
cgilua.cookies.delete
cgilua.cookies.delete ( name string options table nil )
Deletes a cookie with a given name. This function should be called before the HTTP headers are sent and before any output is generated.
Returns nothing.

Serialize

cgilua.serialize
cgilua.serialize ( tab table outfunc function indent string nil prefix string nil )
Serializes a table using outfunc as the function to be used to generate the output; indent as an optional string with the indentation pattern; prefix as an optional string with the indentation prefix (it is used to store the actual indentation between the recursion calls).
Some restrictions must be noted: values of types function and userdata are not serialized; tables with cycles are not serialized.
Returns nothing.

Session

cgilua.session.new
cgilua.session.new () string
Creates a new session identifier.
Returns the new session identifier.
cgilua.session.load
cgilua.session.load () boolean
Loads session data from the session file into cgilua.session.data.
Returns true if successful.
cgilua.session.save
cgilua.session.save ()
Saves the current session data to the session file.
Returns nothing.
cgilua.session.destroy
cgilua.session.destroy ()
Destroys the current session and erases the session data.
Returns nothing.
cgilua.session.logout
cgilua.session.logout ()
Destroys the current session and sends cookie invalidation to client.
Returns nothing.
cgilua.session.cleanup
cgilua.session.cleanup ()
Removes expired session files from the session directory.
Returns nothing.
cgilua.session.data table
Table which holds the user session data.
cgilua.session.id string nil
The current session identifier, or nil if no session is active.
cgilua.session.base_dir string
The directory where session files are stored. Default: /tmp
cgilua.session.timeout number
Session timeout in seconds. Default: 600 (10 minutes)
cgilua.session.token_name string
The name of the session cookie. Default: cgilua_session_identification
